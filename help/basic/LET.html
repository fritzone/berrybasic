LET

Assigns a value to a variable. The keyword LET is optional.

Syntax

[LET] var = expression

Description

Evaluates the expression and stores the result in the variable. A name ending in $ holds a string; a name ending in % holds an integer; any other name holds a floating-point number. Variables spring into being on first use.

Examples

10 LET x = 10 20 y = x * x + 1 30 name$ = "Ada" 40 count% = 0
