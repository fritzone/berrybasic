MODE

Chooses the graphics coordinate system.

Syntax

MODE n

Description

MODE 1 (the default) uses BBC-style logical coordinates: x from 0 to 1279 and y from 0 to 1023, with the origin at the bottom-left, scaled to fit the screen. MODE 2 uses native device pixels with the origin at the top-left, matching the mouse and the framebuffer.

Examples

10 MODE 2 20 CIRCLE 400, 300, 100
