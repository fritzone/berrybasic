SIN

Returns the sine of an angle given in radians.

Syntax

SIN(radians)

Description

Angles are measured in radians (a full turn is 2*PI). The companion functions COS and TAN work the same way; RAD converts degrees to radians.

Examples

10 PRINT SIN(PI/2) : REM 1 20 FOR a = 0 TO 6 : PRINT SIN(a) : NEXT
