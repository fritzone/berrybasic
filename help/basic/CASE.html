CASE ... ENDCASE

Chooses one of several branches by matching a value.

Syntax

CASE expression OF
  WHEN value [, value ...] : statements
  ...
  OTHERWISE : statements
ENDCASE

Description

The expression is compared with each WHEN clause in turn; the first match runs, then control jumps past ENDCASE. If nothing matches, the OTHERWISE clause (if present) runs.

Examples

10 INPUT "Grade 1-3: ", g 20 CASE g OF 30 WHEN 1 : PRINT "gold" 40 WHEN 2 : PRINT "silver" 50 WHEN 3 : PRINT "bronze" 60 OTHERWISE : PRINT "no medal" 70 ENDCASE
