MID$

Returns a substring from the middle of a string.

Syntax

MID$(string$, start [, length])

Description

Extracts characters starting at position start (the first character is 1). With length, at most that many characters are returned; without it, the rest of the string.

Examples

10 PRINT MID$("hedgehog", 4, 3) : REM geh

See also

LEFT$, RIGHT$, LEN, Index
