PROC / DEF PROC

Defines and calls a named procedure with parameters and local variables.

Syntax

DEF PROCname[(param [, param]...)]
  statements
ENDPROC

PROCname[(argument [, argument]...)]

Description

A procedure groups statements under a name. Call it with PROC followed by the name. Parameters are passed by value; declare extra LOCAL variables inside so they do not clash with the caller's. ENDPROC returns.

Examples

10 PROCbox(3) 20 END 30 DEF PROCbox(n) 40 LOCAL i 50 FOR i = 1 TO n : PRINT STRING$(n, "*") : NEXT 60 ENDPROC
