IF

Runs statements conditionally.

Syntax

IF condition THEN statements [ ELSE statements ]

IF condition THEN
  statements
[ ELSE
  statements ]
ENDIF

Description

The single-line form runs the statements after THEN when the condition is true, and those after an optional ELSE when it is false. The block form (ending in ENDIF) spans several lines and may be nested. A condition is any expression; zero is false and any non-zero value is true.

Examples

10 IF score > 100 THEN PRINT "You win!" 20 IF n MOD 2 = 0 THEN PRINT "even" ELSE PRINT "odd" 30 IF lives = 0 THEN 40 PRINT "Game over" 50 END 60 ENDIF
