FN / DEF FN

Defines and calls a function that returns a value.

Syntax

DEF FNname[(param [, param]...)] = expression

DEF FNname[(param [, param]...)]
  statements
  = expression

Description

A function is like a PROC but yields a value, so it can be used inside an expression. The single-line form returns the expression directly; the multi-line form runs statements then returns via = expression.

Examples

10 PRINT FNcube(3) 20 END 30 DEF FNcube(x) = x * x * x
