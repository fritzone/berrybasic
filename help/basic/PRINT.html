PRINT

Writes numbers, strings and the results of expressions to the screen.

Syntax

PRINT [item] [ sep [item] ]... [ sep ]

Each item is a number, a string, or any expression. A sep is a comma or a semicolon.

Description

PRINT evaluates each item and writes it to the console in turn. A comma between items pads to the next tab column so output lines up in fields; a semicolon joins items with no space at all. A comma or semicolon at the very end of the statement suppresses the newline, so the next PRINT continues on the same line. Numbers print in the usual BASIC format; strings print exactly.

Examples

10 PRINT "Hello, world!" 20 PRINT "6 * 7 = "; 6*7 30 FOR I=1 TO 3 : PRINT I, : NEXT 40 PRINT 50 PRINT "x="; x; " y="; y
