PLOT

The general drawing primitive: move or draw to a point.

Syntax

PLOT mode, x, y

Description

The mode selects the action: 4 moves the graphics cursor to (x,y) without drawing, 5 draws a line to it in the current GCOL colour. MOVE and DRAW are handy shorthands for PLOT 4 and PLOT 5.

Examples

10 GCOL 3 20 PLOT 4, 100, 100 30 PLOT 5, 500, 400
