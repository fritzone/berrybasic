REPEAT ... UNTIL

Repeats a block until a condition becomes true.

Syntax

REPEAT
  statements
UNTIL condition

Description

The block runs at least once; after each pass the condition is tested, and the loop ends when it is true. Contrast with WHILE, which tests before the first pass.

Examples

10 n = 1 20 REPEAT 30 PRINT n 40 n = n * 2 50 UNTIL n > 100
