RND

Returns a random number.

Syntax

RND(n)

Description

With a positive whole n, returns a random integer from 1 to n. With n = 1, returns a random fraction from 0 up to (but not including) 1. A common idiom for a dice roll is RND(6).

Examples

10 FOR i = 1 TO 5 : PRINT RND(6); : NEXT 20 PRINT 30 PRINT RND(1) : REM a fraction 0..1
