INPUT

Reads a line typed by the user into one or more variables.

Syntax

INPUT [ "prompt" , ] var [ , var ]...

Description

INPUT prints an optional prompt string, waits for the user to type a value and press Enter, and stores it in the variable. A string variable (name ending in $) takes the whole line; a numeric variable takes a number. Several variables may be filled from one comma-separated reply.

Examples

10 INPUT "What is your name? ", name$ 20 PRINT "Hello, "; name$ 30 INPUT "Enter two numbers: ", a, b 40 PRINT "Their sum is "; a + b
