GOSUB ... RETURN

Calls a subroutine at a line number and returns.

Syntax

GOSUB line
...
RETURN

Description

GOSUB remembers where it was, jumps to the line, and runs until a RETURN sends control back to just after the GOSUB. Named PROCs with parameters are the modern alternative.

Examples

10 GOSUB 100 : PRINT "back" 20 END 100 PRINT "in the subroutine" 110 RETURN
