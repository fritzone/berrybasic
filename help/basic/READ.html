READ

Reads the next constant from the DATA pool into a variable.

Syntax

READ var [, var ]...

Description

Each READ takes the next unread DATA value and stores it in the variable, advancing an internal pointer. Reading past the last value raises an error; use RESTORE to rewind.

Examples

10 READ a, b, c 20 PRINT a + b + c 30 DATA 3, 4, 5
