RECTANGLE

Draws a rectangle outline (or a filled box).

Syntax

RECTANGLE x, y, width, height
RECTANGLE FILL x, y, width, height

Description

Draws a rectangle with its corner at (x,y) and the given width and height in the current GCOL colour. Add FILL for a solid box.

Examples

10 GCOL 4 20 RECTANGLE 100, 100, 300, 150 30 GCOL 1 : RECTANGLE FILL 500, 300, 120, 120
