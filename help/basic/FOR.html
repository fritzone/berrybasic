FOR ... NEXT

Repeats a block of statements a counted number of times.

Syntax

FOR var = start TO limit [ STEP increment ]
  statements
NEXT [ var ]

Description

The loop variable var starts at start and, after each pass, changes by increment (1 if no STEP is given). The loop ends once var passes limit. A negative STEP counts down. Loops may be nested; naming the variable on NEXT makes the pairing explicit.

Examples

10 FOR I = 1 TO 5 20 PRINT I; " squared is "; I*I 30 NEXT I 40 FOR C = 10 TO 0 STEP -2 : PRINT C; : NEXT
