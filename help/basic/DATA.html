DATA

Holds constant values that READ pulls in one at a time.

Syntax

DATA value [, value ]...

Description

DATA lines are not executed; they are a pool of constants. Each READ takes the next value in order. RESTORE rewinds to the first (or a chosen) DATA line. Values may be numbers or strings.

Examples

10 FOR I=1 TO 3 : READ n$, age : PRINT n$; " is "; age : NEXT 20 DATA "Ann", 30, "Bo", 25, "Cy", 41
