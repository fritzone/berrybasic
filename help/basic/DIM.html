DIM

Reserves storage for an array, or a block of memory.

Syntax

DIM name(size [, size ...])
DIM name size

Description

The first form creates an array whose indices run from 0 up to each given size. String arrays (name$) and integer arrays (name%) work too. The second form (a bare name and a byte count) reserves a block of memory and sets name to its address, for use with the ? ! $ indirection operators.

Examples

10 DIM score(10) 20 DIM grid(8, 8) 30 DIM word$(100) 40 DIM mem 256
