WHILE ... ENDWHILE

Repeats a block as long as a condition is true.

Syntax

WHILE condition
  statements
ENDWHILE

Description

The condition is tested before each pass, so the block may run zero times. Contrast with REPEAT, which always runs at least once.

Examples

10 n = 100 20 WHILE n > 1 30 PRINT n 40 n = n / 2 50 ENDWHILE
