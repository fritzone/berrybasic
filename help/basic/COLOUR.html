COLOUR

Sets the text foreground (and background) colour. COLOR is an accepted spelling.

Syntax

COLOUR foreground
COLOUR 128 + background

Description

Colours 0-7 are black, red, green, yellow, blue, magenta, cyan and white. Adding 128 sets the background instead of the foreground.

Examples

10 COLOUR 1 : PRINT "red on black" 20 COLOUR 128 + 4 : COLOUR 7 : PRINT "white on blue"
